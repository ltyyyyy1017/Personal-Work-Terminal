# 金山文檔工作概覽

行政部績效頁可連接原有金山文檔表格。分享連結與官方同步授權是兩件事：瀏覽器能編輯文件，不表示背景服務已獲得 API 授權。未授權時只保存連結，介面明確顯示尚未讀取，不建立虛構的工作或績效。

## 來源與分類

使用金山文檔官方 Skill Hub 工具接口，同時支援普通試算表及多維表格（.dbt）；讀取可見的原有資料表，多維表格保留項目及成員的關聯記錄 ID。首次遇到的頁籤，只有能辨認工作事項及姓名兩個表頭時才建議欄位對應；設定中可核對原表預覽並選擇欄位。未識別的頁籤保留提示，不猜測資料。支援選擇工作日期、所屬活動、具體內容、備註、完成狀態及考核項目。原表分值與所屬類型只讀，不擅自回填評分。

工作按所屬活動分類；無活動欄時按原頁籤建立大事項。原表已完成的記錄直接匯入，未完成的多維表格工作保留原進度。多維表格以原始記錄 ID 識別；普通表格以頁籤、工作、成員、日期識別，重複讀取不累加，移動行時保持身份；本機已修改的內容保留待核對。來源移除時標記缺失，保留紀錄供核對。

## 績效

只有明確對應的成員、有效日期及已確認的準則項目才建立績效原始次數。物資工作還需確認準備／收尾階段，同一人同活動同階段最多一次。多維表格已有的績效分數另列為來源參考，不加入原始計次。未知資料只匯入任務，不補成今天、不猜績效、不換算分數或志願時。刪除來源績效後保留忽略標記，避免下一次讀取重新出現。

## 回填

行政部任務完結時選擇僅工作台紀錄，或指定一個已確認欄位的原頁籤。多維表格另可在完結頁選擇原表已有的項目，保留本機事項與原表歸類各自的用途。只在原頁籤寫入，不建立其他表格。回填包含工作、執行成員與已配置的日期、活動、備註及狀態欄；不自動回填績效分類。修改後更新相同記錄，改為私人紀錄或刪除時恢復工作台寫入前的欄位值。

每筆寫入前保存原值與預期值，寫後讀回核對；網路失敗可重試同一行。人工修改、公式、圖片、合併格或重複候選行會中止覆寫。資料及寫入日誌存放於私人資料目錄，官方授權 Token 使用現有加密保管庫保存，不回傳至頁面。

每小時讀取一次來源，選擇回填的工作改動後排程同步；失敗保留提示並退避。接口包括受登入保護的 `GET /api/kdocs`、`POST /api/kdocs/config` 及 `POST /api/kdocs/sync`。

驗證：`node scripts/check-kdocs.cjs` 使用隔離資料及模擬原表，涵蓋分類匯入、原始績效、欄位缺漏、去重、移動行、人工改動保護、指定原頁籤、回應遺失、部分寫入後清理及來源行採用。正式表的結構與權限仍須在取得授權後實際核對。

多維表格的回填透過 `dbsheet.update_records`／`dbsheet.create_records`，以原有欄位 ID 及關聯記錄 ID 寫入。找不到唯一成員或項目時停止，不新增成員、項目、欄位、選項或分表。來源記錄被重排或改名仍以原始 ID 對應；獨立但內容相同的新工作保持獨立。`node scripts/check-kdocs-database.cjs` 驗證官方 SSE 回應、關聯欄位、來源分值、進度、記錄 ID、重試及人工變更保護。
