# 個人日程篩選

首頁日程、展開月曆與完整日曆共用同一個資料投影。部門事務、原表匯入與績效保留所有工作記錄，日程只挑選與目前本人身份有關的工作，不刪除記錄，也不生成重複日程。

本人身份在「設定 → 我的日程身份」配置，可選多個部門中的成員 ID，並補充簡體、繁體或英文姓名別名。成員 ID 優先；已有明確成員對應時，不因另一個人同名而認領他的工作。舊版文字執行人及尚未配對的來源負責人以完整姓名匹配，避免部分姓名誤判。

日程包含本人執行的任務、來源明確指定本人負責的任務，以及在工作台明確需要本人審核的任務。手動建立的未分派工作及個人事務保留；來源表中未指派本人的記錄不因匯入而進入個人日程。只有其他人成員任務的父事項也不單獨出現在日曆。

金山文檔欄位對應新增只讀的項目負責人，與項目執行者分開儲存。既有連接會補讀負責人欄位；原表同步保留工作台已明確設定的本人審核需求。獨立建立的日程與讀入的 iCloud 原生日程沒有成員任務關聯，維持原來的展示與手動同步行為。

`scripts/check-calendar-entries.mjs` 驗證本人執行、本人負責、跨部門身份、明確審核、同名及部分姓名、無關父事項、來源缺失與資料不變性；`scripts/check-kdocs-database.cjs` 驗證來源負責人及重讀後保留審核設定；完整整合檢查驗證身份設定的保存及錯誤輸入不改動資料。
